# E-commerce Catalog Intelligence

A real-world style portfolio project focused on
e-commerce product catalog management, taxonomy,
data normalization, data quality, and structured
dataset management.

## Objective

Build an AI-ready e-commerce product catalog by
profiling, validating, normalizing, modeling, and
structuring large-scale product data.

## Target Role

E-commerce Data & Catalog Specialist

## Dataset

Dirty E-Commerce Data [80,000+ Products]

The raw dataset is not included in this repository.
See the dataset source and setup instructions below.
